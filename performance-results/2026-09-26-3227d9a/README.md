# MoonPulsar 性能基线（2026-09-26）

本报告为早期单客户端实测，不用于与其他客户端直接比较。源码版本为 `3227d9a`，native release 构建；环境为 Linux x86_64、24 vCPU、约 16 GiB 内存，Pulsar 4.2.4。客户端与 Broker 同机，Token 认证，未启用 TLS 或压缩；主机为共享测试环境。

每组执行三轮。生产者预热 3 秒、测量 20 秒；消费者预热 7 秒、测量 15 秒，测量窗口位于持续生产阶段。队列上限 1000，batch 字节上限 128 KiB、最长等待 1 ms。吞吐为三轮平均值，P99 为三轮发送确认延迟 P99 的中位数，直方图精度为 100 μs。

| 消息 / 并发 / batch 最大条数 | 发送 msg/s | 消费 msg/s | 发送 MiB/s | P99 ms |
| --- | ---: | ---: | ---: | ---: |
| 1 KiB / 1 / 关闭 | 623 | 624 | 0.61 | 3.8 |
| 1 KiB / 32 / 关闭 | 17,251 | 16,983 | 16.85 | 4.7 |
| 1 KiB / 32 / 100 | 9,019 | 8,976 | 8.81 | 6.2 |
| 1 KiB / 32 / 32 | 14,209 | 14,204 | 13.88 | 4.8 |
| 64 KiB / 32 / 100 | 1,602 | 1,604 | 100.13 | 38.0 |

全部正式测试进程正常退出。32 并发无法凑满 100 条 batch，该配置依赖定时器发送；改为 batch=32 后有改善，但仍低于本轮未分批结果。消费者吞吐受生产者供给限制；本报告没有测量端到端延迟、跨机网络、故障负载或长期稳定性。
